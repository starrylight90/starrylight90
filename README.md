# Hi, I'm Swayam Pendgaonkar 👋

**Associate Software Engineer @ A.P. Moller–Maersk** · Building production AI systems, cloud architecture, and cost-optimized LLM infrastructure.

I work across the full stack — from backend systems processing millions of records, to RAG pipelines and agentic AI workflows, to the cloud architecture underneath all of it. Most recently, I've been focused on making AI systems cheaper and faster to run at scale: prompt compression, semantic caching, and intelligent model routing.

- 🔭 Currently building an **AI cost-optimization gateway** — prompt compression, semantic caching, and dynamic model routing to cut LLM token spend at scale.
- 🧠 Also prototyping **VEDA** — a real-time assistive device for the visually impaired: computer-vision object detection driving a tactile Braille display.
- ⚙️ Day to day: backend systems, cloud architecture, RAG pipelines, agentic workflows, and production reliability (testing, hotfixes, hypercare).
- 🎓 B.Tech Computer Science, Symbiosis Institute of Technology — exchange semester at TUHH, Hamburg.
